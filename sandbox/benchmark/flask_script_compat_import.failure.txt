Ground truth root cause: flask_script/__init__.py does `from
flask._compat import text_type` at module load time. flask._compat was
Flask's internal Python 2/3 compatibility shim, removed entirely when
Flask dropped Python 2 support in Flask 2.0. requirements.txt pins
flask>=2.0, so the module doesn't exist and the import fails before any
test body runs. The fix is to stop depending on Flask's private
compat shim — on Python 3, `text_type` is just the builtin `str`.
