Ground truth root cause: flaskext/markdown.py does `from flask import
Markup` at module load time. Flask re-exported `Markup` (really
`markupsafe.Markup`) for backwards compatibility through the 2.x
series, deprecated it in Flask 2.3, and removed the re-export entirely
in Flask 3.0. requirements.txt pins flask>=3.0, so the import fails
immediately, before any test body runs. The fix is to import Markup
from markupsafe directly (`from markupsafe import Markup`), which has
always been the real home of that class.
