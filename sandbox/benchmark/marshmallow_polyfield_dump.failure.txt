Ground truth root cause: polyfield.py's PolyField._serialize does
`schema.context.update(getattr(self, 'context', {}))`, assuming every
Schema instance has a `.context` attribute by default — true in the
marshmallow 2.x/3.x era this code was written against. requirements.txt
pins marshmallow>=4.0,<5; marshmallow 4 dropped that always-present
`context` attribute, so a freshly-instantiated CatSchema() no longer
has one, and the line raises AttributeError (caught and re-raised as
TypeError by polyfield.py's own error handling). The fix is to not
assume `.context` exists — e.g. `schema.context = getattr(self,
'context', {})` guarded by `hasattr`, or set it unconditionally instead
of updating an attribute that may not exist.
