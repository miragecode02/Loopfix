Ground truth root cause: This repo (Flask-SQLAlchemy 2.5.1) only pins
SQLAlchemy>=0.8.0 upstream. SQLAlchemy 2.0 restructured its top-level
package and no longer exposes sqlalchemy.__all__ / sqlalchemy.orm.__all__
the way 1.x did. flask_sqlalchemy/__init__.py's _include_sqlalchemy()
(around line 108-115) iterates module.__all__ for both sqlalchemy and
sqlalchemy.orm to copy every public name onto the convenience db
object, called from SQLAlchemy.__init__ on every db = SQLAlchemy(app).
Once SQLAlchemy is bumped to >=2.0, that raises AttributeError before
any test can even get a working db fixture.
