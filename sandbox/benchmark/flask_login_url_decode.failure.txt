Ground truth root cause: This repo (Flask-Login 0.6.2) pins only
Werkzeug>=1.0.1 upstream. Werkzeug 2.1 removed the deprecated
werkzeug.urls.url_decode/url_encode helpers. flask_login/utils.py
lines 14-15 still import them directly, and login_url() (around line
126-130) uses them to round-trip the "next" redirect query parameter.
Once Werkzeug is bumped to >=2.1, importing flask_login at all raises
ImportError, so every test that touches it fails at collection.
