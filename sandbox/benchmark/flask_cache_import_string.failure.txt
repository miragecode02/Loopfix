Ground truth root cause: flask_cache/__init__.py does `from werkzeug
import import_string` at module load time. Werkzeug used to re-export
several utility functions (including import_string) directly from the
top-level `werkzeug` package; that convenience re-export was dropped
as Werkzeug's public API was cleaned up. requirements.txt pins
flask>=3.0, which pulls in a modern Werkzeug lacking the top-level
re-export, so the import fails before any test body runs. The fix is
to import from the real current location, `werkzeug.utils` (`from
werkzeug.utils import import_string`).
